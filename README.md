# Nachbarhand

Vermittlungs-App für Alltagshilfe in der Nachbarschaft, Testregion **Nordhessen** (Kassel, Baunatal).

Wer Hilfe braucht (oder Angehörige, die für ihre Eltern buchen), sagt per Knopfdruck und Sprache, was gebraucht wird: Rasen mähen, Einkaufen, Begleitung zum Arzt, Hilfe am Handy. Ein Assistent, die „Alleskönner“-Figur mit Werkzeuggürtel, die aus einer Lampe aufsteigt, fragt die Details ab. Geprüfte Helfer aus der Nähe, vor allem fitte Rentner und Minijobber, die nebenbei etwas verdienen wollen, finden den Auftrag auf einem Monitor, schlagen einen Preis vor und besiegeln ihn per Handschlag.

- **Modell:** reine Vermittlung, 15 % Provision vom Helfer, Zahlung in der App
- **Zielgruppe Kunden:** Angehörige und Berufstätige ohne Zeit, ältere Menschen (bewusst *nicht* als „Rentner-App“ vermarktet)
- **Sprache:** Deutsch, Spracheingabe auch Türkisch, Russisch, Arabisch
- **Stand (25.10.2026):** Name steht, klickbares Mockup fertig, noch kein Code
